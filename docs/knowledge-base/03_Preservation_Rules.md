# MODULE 3: ARCHITECTURAL PRESERVATION PROTOCOL
## NON-NEGOTIABLE Rules for Legal Compliance

**Priority**: ABSOLUTE (Overrides ALL other considerations)  
**Legal Requirement**: Modifying architecture = False advertising = Lawsuits  
**Violation**: Automatic rejection, regeneration mandatory

---

## CORE PRINCIPLE

**HOUSPIRE VIRTUAL STAGING PRESERVES 100% OF ARCHITECTURAL ELEMENTS**

The original photo shows the ACTUAL property being sold/rented. ANY modification to architectural elements constitutes false advertising and violates real estate laws.

---

## WHAT MUST BE PRESERVED (LOCKED ELEMENTS)

### 🚪 DOORS - ABSOLUTELY LOCKED

**CANNOT Modify:**
- ❌ Door position (must stay in exact location)
- ❌ Door size (width and height locked)
- ❌ Door style (panel design, frame, hardware)
- ❌ Door color (unless repainting entire room)
- ❌ Door quantity (cannot add or remove doors)
- ❌ Door orientation (swing direction, single/double)
- ❌ Door frame (trim, molding, threshold)
- ❌ Door hardware visibility (handles, hinges if visible)

**CAN Modify:**
- ✅ Paint/finish color IF repainting all doors consistently
- ✅ Add decor NEAR door (not blocking, not on door)
- ✅ Change floor near door (keeping door threshold intact)

**Verification Checklist:**
```
Before Output - Check Each Door:
☑ Position matches original photo exactly?
☑ Size (width × height) identical?
☑ Style/paneling preserved?
☑ Frame/trim intact?
☑ Not blocked by new furniture?
☑ Visible in render if visible in original?

IF ANY = NO → REJECT RENDER → REGENERATE
```

**Common Violations to AVOID:**
- ❌ "Improving" door style to more modern
- ❌ Moving door to "better" position
- ❌ Removing door to "open up space"
- ❌ Adding door where none exists
- ❌ Changing door swing direction
- ❌ Partially obscuring door with furniture

---

### 🪟 WINDOWS - ABSOLUTELY LOCKED

**CANNOT Modify:**
- ❌ Window position (exact location locked)
- ❌ Window size (dimensions locked)
- ❌ Window style (casement, sliding, bay, etc.)
- ❌ Window frame (material, color, trim)
- ❌ Window quantity (cannot add or remove)
- ❌ Window panes (grid pattern if present)
- ❌ Window sill (height, depth, material)
- ❌ Window hardware (visible handles, locks)

**CAN Modify:**
- ✅ Add curtains/drapes (hanging above/beside window)
- ✅ Add blinds/shades (inside window frame)
- ✅ Change view SLIGHTLY (if adding greenery outside)
- ✅ Adjust glass reflection/glare (subtle)

**Verification Checklist:**
```
Before Output - Check Each Window:
☑ Position exactly matches original?
☑ Size identical (width × height)?
☑ Style preserved (casement/sliding/etc.)?
☑ Frame and trim intact?
☑ Number of panes matches?
☑ Window sill preserved?
☑ Not obscured by furniture?

IF ANY = NO → REJECT RENDER → REGENERATE
```

**Window Treatment Rules:**
```
Curtains/Drapes:
✅ Hang from rod ABOVE window
✅ Fall beside window (not blocking)
✅ Can be drawn open or closed
✅ Must not change window size perception

Blinds/Shades:
✅ Mount INSIDE window frame
✅ Can be raised/lowered
✅ Must not alter window dimensions
```

### 🧱 WALLS - STRUCTURE LOCKED

**CANNOT Modify:**
- ❌ Wall position/layout (room shape locked)
- ❌ Wall quantity (cannot add or remove walls)
- ❌ Wall height (ceiling height locked)
- ❌ Wall openings (arches, pass-throughs)
- ❌ Built-in elements (niches, shelves, cabinets)
- ❌ Structural columns/beams
- ❌ Room dimensions (length, width, height)

**CAN Modify:**
- ✅ Wall color (paint/wallpaper)
- ✅ Wall texture (finish, sheen)
- ✅ Add wall art (hanging on wall)
- ✅ Add wall-mounted items (sconces, shelves)
- ✅ Add wall decor (mirrors, clocks)

**Verification Checklist:**
```
Before Output - Check Walls:
☑ Room shape identical?
☑ Number of walls same?
☑ Wall positions preserved?
☑ Built-in features intact?
☑ Columns/beams present if in original?
☑ Room dimensions unchanged?

IF ANY = NO → REJECT RENDER → REGENERATE
```

---

### 🏗️ CEILING - HEIGHT & FEATURES LOCKED

**CANNOT Modify:**
- ❌ Ceiling height (locked to original)
- ❌ Ceiling shape (flat, vaulted, tray, etc.)
- ❌ Ceiling beams (if exposed)
- ❌ Ceiling architectural details (molding, coffers)
- ❌ Ceiling openings (skylights, vents)

**CAN Modify:**
- ✅ Ceiling color (paint)
- ✅ Add ceiling lights (fixtures)
- ✅ Add ceiling fan (MANDATORY in India)
- ✅ Lighting fixtures (chandeliers, pendants)

**Ceiling Fan Requirements:**
```
IF: Indian interior
THEN: Ceiling fan is MANDATORY
  - Contemporary BLDC design
  - Center of room (or appropriate position)
  - 7-9 feet mounting height
  - 48-52 inch blade span
  - Modern, clean design
```

---

### 🔲 FLOOR - LAYOUT LOCKED

**CANNOT Modify:**
- ❌ Floor level (height/elevation)
- ❌ Floor layout (room footprint)
- ❌ Floor openings (stairs, transitions)
- ❌ Floor structural changes (platforms, sunken areas)

**CAN Modify:**
- ✅ Flooring material (wood, tile, marble, etc.)
- ✅ Flooring finish (polish, matte, texture)
- ✅ Flooring color/pattern
- ✅ Add rugs (on top of floor)

**Floor Modification Rules:**
```
Changing Flooring Material:
✅ Can change: Tile → Wood, Marble → Tile, etc.
✅ Must maintain: Same level, Same layout
✅ Must show: Realistic floor-to-wall transition
✅ Must preserve: Original floor outline/shape

Adding Rugs:
✅ Rugs sit ON TOP of floor
✅ Floor beneath rug still visible at edges
✅ Rug doesn't change floor structure
```

## AUTOMATIC REJECTION CRITERIA

**Render is AUTOMATICALLY REJECTED if:**

1. ❌ **Door modified in ANY way** (position, size, style, removed, added)
2. ❌ **Window modified in ANY way** (position, size, style, removed, added)
3. ❌ **Wall structure changed** (added, removed, moved)
4. ❌ **Room dimensions altered** (bigger, smaller, different shape)
5. ❌ **Ceiling height changed**
6. ❌ **Floor layout modified** (level changes, structural alterations)
7. ❌ **Architectural features removed** (columns, beams, niches, built-ins)
8. ❌ **Door/window blocked by furniture** (not visible when should be)

**IF ANY VIOLATION → DO NOT OUTPUT → REGENERATE WITH CORRECTIONS**

## EDGE CASES & CLARIFICATIONS

### Q: Can I "clean up" a damaged door?
**A: NO.** Show the door exactly as it appears. Do not repair, improve, or alter.

### Q: Can I make the window appear cleaner (less dirty)?
**A: YES**, subtly. Clean glass is acceptable. But cannot change window size, frame, or style.

### Q: Can I change ugly wall color?
**A: YES**. Wall color/paint is modifiable.

### Q: Can I remove a door if it "looks better" without it?
**A: NO.** NEVER remove doors.

### Q: Can I add a window to bring in more light?
**A: NO.** NEVER add windows that don't exist.

### Q: Can I move furniture in front of door?
**A: NO.** Door must remain visible and accessible.

### Q: Can I add built-in shelving that wasn't there?
**A: NO.** Cannot add structural/built-in elements.

### Q: Can I change floor from tile to hardwood?
**A: YES.** Floor material is modifiable (keeping same layout).

### Q: Can ceiling fan position be adjusted?
**A: MINIMAL adjustment** for aesthetics, but generally center of room.
